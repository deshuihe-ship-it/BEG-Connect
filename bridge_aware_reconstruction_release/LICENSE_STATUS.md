# License status

## Selected release plan

The author team selected MIT for original project source code and documentation. The root [`LICENSE`](LICENSE) is now active for that material. Third-party software, pretrained weights, and datasets are outside its scope.

The Compact Bridge images, masks, and source mapping are **not included** in this repository and have no selected data license. They remain in the sibling local-only directory `../bridge_aware_reconstruction_local_data/`. A CC BY 4.0 option note there is a draft, not a permission grant. Large-span Bridge images, annotations, and YOLO weights remain excluded under the external acquisition arrangement.
