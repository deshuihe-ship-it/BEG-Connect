# Third-Party Software, Model, and Data Notices

Audit snapshot: 2026-09-22. This document inventories dependencies referenced by the files in this release candidate and packages declared in `environment/requirements-minimal.txt`. It is not a legal opinion, a software bill of materials (SBOM), or proof of the versions used in the paper experiments.

## Scope and license boundary

The project-level MIT license in the repository root applies only to original project code and documentation for which the author team has authority to grant that license. It does not relicense third-party software, pretrained weights, datasets, example images, or generated assets. Each user is responsible for obtaining external components and complying with the license and terms applicable to the exact version and use.

No third-party source repository, executable, pretrained model checkpoint, or dataset is intentionally bundled in this release candidate. Some scripts call external software or expect external model repositories and weights to be installed separately. The list below records upstream license information visible in the cited project sources as of the audit date; because this project does not pin dependency versions or original experiment commits, verify the license files shipped with the exact versions actually installed before redistribution.

## Models, datasets, and other external materials

- No Compact Bridge or Large-span Bridge images, masks, annotations, camera poses, checkpoints, or pretrained weights are included in this repository snapshot.
- The local Compact Bridge data directory is outside this release package and has no selected redistribution license. Do not upload it unless the data/rightsholder and site/privacy permissions have been established.
- Large-span Bridge images, annotations, and YOLO weights were obtained under a separate arrangement and remain excluded. The permission to access or use them for the research does not by itself establish permission to redistribute them.
- Downloaded checkpoints, LPIPS feature weights, DINOv2/LightGlue/RoMa/ALIKED weights, and any weights used in historical YOLO experiments are distinct artifacts. Check their exact origin, model card, license, and any access/use restrictions before redistributing them.
- Reference datasets and images used by upstream projects are not included in this package. Their terms remain separate from the software licenses.

## Before publication

1. Pin the supported Python/package versions and, where applicable, Git commit IDs; record the original experimental environment separately from a newly tested public environment.
2. Remove unused entries (`openpyxl` and `ultralytics`) from the requirements inventory, or document a concrete retained script that needs them. Do not leave a misleading dependency list.
3. Generate a transitive dependency/SBOM report for the tested environment and preserve the license/notice files shipped in its wheels and native binaries. This is particularly important for PyTorch, NumPy, OpenCV, Nerfstudio, COLMAP, and HDF5 builds.
4. Record provenance and terms for every model checkpoint or metric weight needed for a reproduction workflow; keep restricted or unlicensed weights out of the repository.
5. Re-scan the Git staging area before upload for datasets, private paths, credentials, executable binaries, model weights, and generated data files.

This inventory is provided for attribution and user awareness. It is not a substitute for the license texts or legal advice. Upstream license pages may change; the license included with the exact package version or artifact distributed is controlling.
