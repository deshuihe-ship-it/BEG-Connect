# Method-to-file map and reproducibility boundary

The method labels below follow the revised manuscript. They are not interchangeable with old workspace names.

| Paper setting | Implementation or status |
|---|---|
| VT | Conventional visual-transformer matching baseline; its original external dependency and final run recipe still need provenance verification. |
| DL | `src/matching/paper_methods/dl_dinov2_lightglue.py` (Large-span Bridge historical implementation). |
| DL+E | Bridge enhancement stage of `beg_connect_conservative_expansion.py`; a separately runnable final-ablation driver was not verified. |
| DL+G | Guided temporal expansion stage of the same script; a separately runnable final-ablation driver was not verified. |
| BEG | Complete BEG-Connect script `beg_connect_conservative_expansion.py`. |
| BG | Final BG run code was not verified; do not substitute the BEG script. |
| BEG-C | BEG-Connect reconstruction with ordinary Nerfacto. |
| Complete | BEG-Connect followed by BEG-NeRF bridge patch fine-tuning and residual refinement. |
| D-R / D-R-BEG | `src/matching/roma_comparison/dl_roma.py` and `dl_roma_beg_connect.py`. |

BEG-NeRF has two actual training components: `train_beg_nerf_v2.py` for bridge-biased patch fine-tuning and `train_render_refiner.py` plus `render_refiner_model.py` for residual image refinement. `prepare_beg_nerf_v2.py`, `cache_render_refiner_pairs.py` and the evaluation scripts are supporting stages. The Compact Bridge wrappers call the same shared implementation with scene-specific workspace defaults.

The Compact Bridge masks in the local-only holdback were generated by a deterministic bridge-region mask workflow (`src/matching/generate_bridge_region_masks_v3_1.py`). A historical local ablation script (`data/daqiao/_scripts/run_ablation_completion.sh`, outside this package) confirms that the Compact Bridge DL/BEG run adapted the shared matching implementation and used these V3.1 masks in place of YOLO output. That script hard-codes private paths and is not a release command. Large-span Bridge matching used a trained YOLO segmentation weight that is not redistributable here. Neither scene should be described as having a released SAM model; no SAM prompt protocol or weights are available in this package.

The legacy scripts refer to the author's machine and private reconstructed geometry. Exact reported metrics require their original inputs, split manifests, checkpoints and dependency versions; those have not been included. `results/table15_repeatability_seed42_43_44.json` is a compact numerical summary, not a checkpoint or a rerun manifest. The common-50 RoMa comparison script is included under `src/evaluation/paper_results/`; its original result JSON was excluded because it embeds private absolute paths.

Before GitHub publication: verify software and image licenses, replace private paths in the remaining legacy/comparison scripts, pin dependency versions, identify the exact VT/BG and individual-ablation drivers if those are promised, and run at least one clean-room end-to-end example. No public release or remote upload has been performed.
